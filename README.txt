- `assets/pckl-bol-neo.png` — supplied PCKL BOL NEO product artwork

## Deploy to Cloudflare Pages
1. Unzip this folder.
2. In Cloudflare Pages, open your existing PCKL BLOCK project.
3. If the project is connected to GitHub, replace the repository's `index.html`, `styles.css`, and `assets/` files, commit, and push. Cloudflare Pages should redeploy automatically.
4. If using direct upload, upload the contents of this folder (the `index.html`, `styles.css`, and `assets` folder), not the ZIP file itself, through the Pages upload flow.
